# Hospital Network Design and Simulation

## Project Overview
This project presents the design and simulation of a hospital network using Cisco Packet Tracer.

The network connects multiple hospital departments through a structured network architecture, with IP subnetting, VLAN segmentation, and routing to support communication between departments.

## Technologies Used
- Cisco Packet Tracer
- TCP/IP Networking
- VLANs and Subnetting
- Routing and Switching
- Network Security
- Network Troubleshooting

## Hospital Departments
- Intensive Care Unit (ICU)
- Cardiology Department
- Administration
- Data Center
- Demilitarized Zone (DMZ)

## Project Objectives
- Design a hospital network topology.
- Create separate networks for hospital departments.
- Implement IP addressing and subnetting.
- Configure routers and switches.
- Establish communication between authorized departments.
- Verify connectivity using simulation tools.

## Network Topology
The network topology was designed and simulated using Cisco Packet Tracer.

## Simulation File
The Cisco Packet Tracer project file is included in this repository.

Open the `.pkt` file using Cisco Packet Tracer to explore the network configurations and run the simulation.
